# **App Name**: ProductionFlow

## Core Features:

- Production Calendar Display: Displays a traditional calendar view where you can add products per bay per day using dropdowns. Each bay is color-coded, facilitating clear visual organization. Editing the task and products will be displayed here for quick referencing
- Products & Batches editing: Allows the addition and removal of products and the numbers of batches of each, that will populate the days on the "Production Calendar" tab with a + and x button.
- Task Designator Display: Displays all the active batches/products that are actively in the production calendar to allow adjustments per bays task
- Tasks visibility Control: Provides an interactive system to show and hide tasks under the "Task Designator" tab.  Functions under each task to customize it's visibility with toggle.
- Assigned Tasks Display: Shows the assigned tasks, quantities and associated employee per bay within a "Assigned Tasks Tab", giving you quick referencing to the tasks assigned for production bays on this tab.
- AI - Production insights tool: Generates a tool using an LLM that can identify discrepancies, delays and common problems found in past data in the "Assigned Task Tab"  and suggests proactive responses to improve production flow.
- Login Page: Require secure credentials to control access to ProductionFlow functionalities for security

## Style Guidelines:

- Primary color: Steel blue (#4682B4) to invoke a sense of dependability and stability, representing the structured nature of the production environment.
- Background color: Light gray (#F0F8FF), nearly the same hue as the primary, desaturated to create a professional backdrop that ensures legibility and reduces visual fatigue.
- Accent color: Burnt orange (#CC7722) for interactive elements and to draw attention to key functionalities.
- Body and headline font: 'Inter', a sans-serif font to ensure clear and highly legible UI.
- Use clear, geometric icons to represent actions (e.g., add, delete, edit, assign).  Ensure icons are distinct and intuitively understandable to reduce cognitive load.
- Divide each bay with bold containers or bars within the 'Assigned Tasks' page to keep consistency. Ensure easy understanding and readability on information to reduce ambiguity.
- Implement subtle transitions (e.g., fading or sliding) for UI elements, and a soft transition is triggered on navigation/hover over features.
